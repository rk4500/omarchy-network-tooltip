# archer.network

Omarchy network panel with a hover tooltip showing SSID and signal (or interface name).

A modified copy of the built-in `omarchy.network` plugin from [Omarchy](https://github.com/basecamp/omarchy) (MIT). It replaces the stock plugin when enabled; `omarchy plugin remove archer.network` restores it.

Install: `omarchy plugin add <this repo's git URL> --enable`

Personal config, shared as-is: no support or compatibility promises.
